👤 Tentang Website

Website ini dibuat sebagai media pembelajaran interaktif tentang Pancasila. Halaman utama dapat dipublikasikan melalui GitHub Pages, sedangkan kuisnya terhubung dengan Google Apps Script.

Dengan konsep ini, website bisa tetap gratis, mudah dibagikan, dan dapat dikembangkan lagi menjadi portal kuis dengan banyak topik.
